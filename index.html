About the Frontend Track

The frontend is the part of a website that you see and click. In this track you learn how to build it step by step.

📘

What it is

A beginner-friendly course about building the visible part of websites: text, images, buttons and menus.

🎓

What you learn

HTML for structure, CSS for design and JavaScript for interaction.

👥

Who it is for

Beginners, students and anyone who wants to start a career in web development.

🏆

What you can achieve

Build your own portfolio website and publish it online for everyone to see.

What You'll Learn

Think of a house: HTML is the walls, CSS is the paint and JavaScript is the electricity that makes things work.

🧱

HTML

Create the structure of a page: headings, paragraphs, images, links and forms.

🎨

CSS

Style your page with colors, fonts, spacing and layouts.

📱

Responsive Design

Make your website look good on phones, tablets and computers.

⚡

JavaScript

Add logic and interaction: buttons, menus and forms that react to the user.

🌳

DOM Manipulation

Use JavaScript to change the page: text, styles and elements.

🛠️

Web Fundamentals

Learn how the web works, plus Git and GitHub to publish your work.
