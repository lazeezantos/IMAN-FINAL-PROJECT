# IMAN Bootcamp - Frontend Track Website

A simple, responsive website that introduces the IMAN Bootcamp Frontend Track:
what students learn, example projects, testimonials, FAQ and a registration form.

## Technologies
- HTML
- CSS (variables, Grid, Flexbox, media queries)
- JavaScript (DOM manipulation, events)

## Main Features
- Responsive layout for mobile, tablet and desktop
- Mobile navigation menu (☰)
- FAQ accordion
- Project filtering by category
- Contact form with validation
- Dark / light mode (bonus)
